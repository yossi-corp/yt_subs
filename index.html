Homelab Playlist Automation

Welcome to Homelab Playlist Automation

Homelab Playlist Automation is a personal Python script designed to automatically add new videos from specific YouTube channels to my private "homelab" playlist. This application is for my personal use only and is not available to the public.

The script uses the YouTube Data API to fetch recent videos from my subscribed channels and adds them to my playlist based on my predefined preferences. It runs daily on my homelab server to keep my playlist updated.

Key Details

  • Purpose: Automate the organization of YouTube videos into my personal "homelab" playlist.
  • User Base: Single user (myself).
  • Authentication: Uses OAuth 2.0 to securely access my YouTube account.
  • Data Usage: Only accesses my YouTube subscriptions and playlist data, with no data shared or stored externally.

This application is a personal project and is not intended for commercial use or distribution.
