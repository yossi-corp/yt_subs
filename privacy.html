Homelab Playlist Automation

Privacy Policy

Effective Date: April 16, 2025

Homelab Playlist Automation is a personal Python script created and used solely by its developer for managing a private YouTube playlist. This application is not available to the public, and no other users have access to it. This Privacy Policy outlines how the application handles data.

Data Collection

The application uses the YouTube Data API to access my YouTube account’s subscriptions and playlist data. It does not collect, store, or process any personal data from other users, as it is designed for my personal use only.

Data Usage

The application accesses the following data via the YouTube Data API:

  • My YouTube subscriptions to identify new videos from specific channels.
  • My "homelab" playlist to check for existing videos and add new ones.

This data is used solely to automate the addition of videos to my playlist and is not shared, stored externally, or used for any other purpose.

Data Sharing

As a personal-use application, no data is shared with third parties. The application runs on my private homelab server and does not transmit data to external services beyond the YouTube Data API.

Security

The application uses OAuth 2.0 for secure authentication with my YouTube account. Access tokens are managed securely using Doppler, a secrets management tool, and are stored on my private server with strong authentication measures (e.g., passkeys and MFA).
